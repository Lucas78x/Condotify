Quero criar uma versão mobile completa do projeto Condotify utilizando .NET MAUI Blazor Hybrid, aproveitando ao máximo a arquitetura, os serviços, os modelos, as regras de negócio, os componentes Razor e as APIs que já existem no projeto atual.

O aplicativo deve utilizar MudBlazor e manter a mesma identidade visual da plataforma web, porém com uma experiência adaptada para celulares e tablets.

## Objetivo do aplicativo

O aplicativo será voltado principalmente aos usuários finais e operacionais da plataforma, incluindo:

* Moradores;
* Porteiros;
* Síndicos;
* Administradores;
* Funcionários do condomínio;
* Zeladores;
* Prestadores de serviço;
* Equipes de segurança;
* Operadores de monitoramento;
* Outros usuários cadastrados na plataforma.

O aplicativo não deve ser apenas uma versão reduzida do painel administrativo.

Ele deve disponibilizar todas as funcionalidades da plataforma que sejam úteis e permitidas para o usuário autenticado, sempre respeitando:

* Perfil;
* Função;
* Condomínio;
* Unidade;
* Permissões;
* Dispositivos disponíveis;
* Regras configuradas na plataforma;
* Limitações da API;
* Políticas de segurança.

O usuário deve visualizar apenas os módulos, condomínios, unidades, câmeras, dispositivos e ações para os quais possui autorização.

## Arquitetura esperada

Utilize .NET MAUI com Blazor Hybrid para permitir o reaproveitamento de componentes Razor e a utilização do MudBlazor.

Sempre que fizer sentido, organize a solução em projetos como:

* Condotify.Domain;
* Condotify.Application;
* Condotify.Contracts;
* Condotify.Shared;
* Condotify.ApiClient;
* Condotify.Infrastructure;
* Condotify.Web;
* Condotify.Mobile.

O projeto mobile não deve acessar diretamente:

* Banco de dados;
* Entity Framework;
* Repositórios de infraestrutura;
* Credenciais de dispositivos;
* Senhas de câmeras;
* Serviços internos não expostos;
* Configurações sensíveis.

Toda comunicação deve acontecer por meio de APIs autenticadas ou serviços compartilhados apropriados.

Não mova regras críticas de segurança para o aplicativo.

As permissões devem continuar sendo validadas no servidor, mesmo quando o aplicativo ocultar visualmente uma função.
